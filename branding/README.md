# Marca Dev+ Control

Coloque sua logo PNG com transparência em `branding/devplus-logo.png`.
Na raiz do repositório, execute `bun run branding:generate`.
O script mantém a proporção, centraliza em uma tela transparente e gera ICO
multirresolução, ICNS, PNGs, favicon, manifesto e ícone da bandeja.
Sem a logo, os recursos originais são preservados temporariamente.
O build Windows também executa esse comando automaticamente.
